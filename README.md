## What is boostUP?

A Windows desktop app that helps gamers squeeze every last frame out of their PC — cleaner system, faster network, lower latency.

### 🚀 Core Features

| Feature | What it does |
|:--------|:-------------|
| 🚀 **FPS Booster** | One-click optimization that tunes your system for gaming |
| 🌐 **Network Optimizer** | Reduce latency, smart routing, faster DNS |
| 🔧 **Hardware Monitor** | Live CPU, GPU, RAM, temperature & network tracking |
| 🎮 **Game-Ready Profiles** | Auto-optimization when you launch your favorite games |
| ⚡ **Clean & Lightweight** | Minimal footprint, maximum performance |
