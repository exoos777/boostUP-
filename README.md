## What is boostUP?

A Windows desktop app that helps gamers get the most out of their PC:

- 🚀 **FPS Booster** — one-click optimization that tunes your system for gaming
- 🌐 **Network Optimizer** — reduce latency, smart routing, faster DNS
- 🔧 **Hardware Monitor** — live CPU, GPU, RAM, temperature, and network tracking
- 🎮 **Game-Ready Profiles** — auto-optimization when you launch your favorite games
- ⚡ **Clean & Lightweight** — 4 GB RAM minimum, only 200 MB of disk space
